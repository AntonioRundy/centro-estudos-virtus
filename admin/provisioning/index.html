Nova matrícula

Introduza o nome completo e o perfil. O sistema gera o utilizador e cria a conta com palavra-passe inicial.

A conta é criada com a palavra-passe temporária 123456. No primeiro acesso, o utilizador deverá definir uma palavra-passe pessoal.

Utilize apenas para criar o primeiro Professor Administrador. Depois, este endereço requer uma sessão de Professor Administrador.

Atribuições pedagógicas

Relacione cada aluno a um professor e disciplina. Professores só verão alunos que lhes foram atribuídos.
